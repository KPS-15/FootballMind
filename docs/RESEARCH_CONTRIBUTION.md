# Research Contribution & Novelty

## Core Innovations
1. **Explainable Action Intention Forecasting**: Traditional sports analytics models focus strictly on event tagging post-facto. FootballMind introduces multi-step temporal action intention forecasting paired with SHAP attribution cards.
2. **Quantitative Defensive Collapse Index**: Translates geometric spatial relationships (CB-LB gaps, passing lane exposures, unmarked attacker space) into a continuous, real-time risk index.
3. **Counterfactual What-If Simulation**: Provides tactical analysts with the ability to manually tweak player locations and observe the exact model-derived changes in passing lane viability and xG.
4. **Goal Sequence Reconstruction**: Reconstructs the 5-10 second sequence preceding goal events to identify the primary structural defensive failure.
